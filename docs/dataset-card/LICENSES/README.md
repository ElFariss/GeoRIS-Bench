# Source rights audit — 2026-11-08

This is a Phase 0 recommendation. **No source is approved for publication or
benchmark ingestion yet.** "GO" is a recommendation limited to the artifact
and conditions in that row; it does not authorize a release. "HOLD" means
essential evidence is missing. "NO-GO" applies to the stated use.

| Source and audited use | Recommendation | Evidence and release boundary |
| --- | --- | --- |
| OpenStreetMap, fresh extracts for the two proposed scenes | **GO**, with conditions | [OSM copyright and license](https://www.openstreetmap.org/copyright), [ODbL 1.0 §§4.3–4.6](https://opendatacommons.org/licenses/odbl/1-0/), [OSMF attribution](https://osmfoundation.org/wiki/Attribution_Guidelines) and [Produced Work guideline](https://osmfoundation.org/wiki/Licence/Community_Guidelines/Produced_Work_-_Guideline). Pin source, extract date, bounds and hash before use. Treat the modified or converted geometry database as an ODbL derivative; make the derivative or reproducible alteration files available where required. Use “© OpenStreetMap contributors” with the copyright link in dataset notices and figures. Do not assume the channel/trajectory archive is an independent Produced Work: document what geometry and path coordinates can be reconstructed from it, keep the geography layer separate, and apply ODbL where needed. Additional sources (such as terrain elevation) need separate checks before inclusion. |
| Sionna RT **2.0.1 code** | **GO** as a pinned dependency | The [tagged license](https://github.com/NVlabs/sionna-rt/blob/v2.0.1/LICENSE) and installed wheel notice say Apache-2.0. Keep applicable notices for any redistributed code. This does not change the license of scene data. |
| Sionna RT **Munich** | **GO**, under the OSM conditions | The [tagged scene declaration](https://github.com/NVlabs/sionna-rt/blob/v2.0.1/src/sionna/rt/scene.py#L1228-L1238) explicitly identifies OSM provenance and ODbL. Recommend pinning the upstream scene, publishing the extraction/selection scripts and hashes, and using the native XML/PLY geometry for placements. Treat any exported or edited geography as above. Audit does not authorize copying the raw meshes off the tracing host. |
| Sionna RT **Étoile (Paris), Florence, San Francisco** | **GO**, under the same OSM conditions, if chosen | Each is explicitly OSM/ODbL in the [tagged scene declarations](https://github.com/NVlabs/sionna-rt/blob/v2.0.1/src/sionna/rt/scene.py#L1215-L1265). Not selected as train, validation or test here. |
| Sionna RT **simple_street_canyon**, rectangular synthetic scene | **GO** for controlled simulations; any repackage must carry upstream notices | The [tagged package](https://github.com/NVlabs/sionna-rt/tree/v2.0.1/src/sionna/rt/scenes/simple_street_canyon) bundles a simple synthetic scene; the pinned scene docs describe blocks and a ground plane. Use the dependency instead of repackaging its meshes. This verdict does not cover the canyon-with-cars or other unaudited bundled assets. |
| DeepMIMO-hosted **ASU Campus 3.5 GHz** (`asu_campus_3p5`) | **HOLD** | [Scenario page](https://www.deepmimo.net/scenarios/v4/asu_campus_3p5), [official tutorial](https://www.deepmimo.net/docs/tutorials/1_getting_started.html), [releases](https://github.com/DeepMIMO/DeepMIMO/releases). The tutorial demonstrates downloadable BS-to-grid data. It does not establish the right to redistribute new channel realizations from the source geometry, or confirm access to a retraceable scene with validated materials at arbitrary RIS probe positions. |
| DeepMIMO-hosted **City 18 Denver 3.5 GHz** (`city_18_denver_3p5`) | **HOLD** | [Scenario page](https://www.deepmimo.net/scenarios/v4/city_18_denver_3p5), [official migration guide](https://www.deepmimo.net/docs/tutorials/8_migration_guide.html), [releases](https://github.com/DeepMIMO/DeepMIMO/releases). The guide demonstrates channel generation from the archive. A format spec or a hull view is not proof of access to the original material-aware scene, nor of rights to distribute the resulting channels. |
| DeepMIMO-hosted **Outdoor 1, 28 GHz** (`O1_28`) | **HOLD** | [Legacy scenario page](https://www.deepmimo.net/scenarios/o1-scenario/), [official spec](https://www.deepmimo.net/docs/resources/specs.html), [releases](https://github.com/DeepMIMO/DeepMIMO/releases). The documented scenario name and channel download do not establish geometry access or a release grant for a new retrace. The existing 28 GHz data is **NO-GO** as a substitute for 5.53 GHz BS–RIS and RIS–UE paths. |
| DeepMIMO **4.0.5 code** (including its OSM pipeline) | **HOLD** for vendoring or redistributing the code; dependency-only for internal work | At the same tag, [LICENSE](https://github.com/DeepMIMO/DeepMIMO/blob/v4.0.5/LICENSE) contains Apache-2.0, while [pyproject.toml](https://github.com/DeepMIMO/DeepMIMO/blob/v4.0.5/pyproject.toml) declares GPL-2.0-or-later and points at that file. Get a version-specific clarification before repackaging; avoid copying code into this project. The upstream [OSM pipeline example](https://github.com/DeepMIMO/DeepMIMO/blob/v4.0.5/docs/applications/4_osm_pipeline.py) already exists. | **PyNEC 2.3.4 / NEC++** | **GO** for numeric `Z_RIS` generated from our own wire geometry | [PyNEC 2.3.4](https://pypi.org/project/PyNEC/2.3.4/) declares GPL-3.0-only; [NEC++](https://github.com/tmolteno/necpp) has separate GPL notices ([COPYING](https://github.com/tmolteno/necpp/blob/master/COPYING)). The [FSF output distinction](https://www.gnu.org/licenses/gpl-faq.en.html#WhatCaseIsOutputGPL) concerns content copied from the solver; ordinary impedance numbers from our own inputs do not contain solver code. Ship numbers, geometry, run provenance and hashes. Do not bundle the PyNEC binary, the NEC++ library or their source as part of the data release. |

The hosted list is the initial shortlist, not a blanket verdict on the catalog.
The provider's [license page](https://www.deepmimo.net/license) asks for
citation, including scenario-specific references. That is not enough to
verify an explicit downstream redistribution grant. The [tagged API
client](https://github.com/DeepMIMO/DeepMIMO/blob/v4.0.5/deepmimo/api/download.py)
defines an optional `rt_source` query; availability and license for an
individual source archive were not verified. No candidate archive was
downloaded or traced during this audit. To lift a HOLD, obtain terms for that
specific asset version and evidence of the actual retraceable geometry.
A scripts-only route is a separate decision if retracing is allowed but
redistributing the derived channels is not.
